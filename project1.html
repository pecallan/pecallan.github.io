Game of Thrones Network Analysis

Project Overview

This project uses network analysis to explore connections between characters in A Storm of Swords.

Research Question

How are character relationships structured within A Storm of Swords, and which characters occupy the most central positions within the network?

Methodology

This project uses social network analysis to examine character co-occurrences in George R. R. Martin's A Storm of Swords.

Each character represents a node in the network, while connections (edges) represent characters whose names appear within 15 words of one another in the text. Edge weights indicate how frequently these co-occurrences occur.

The network was explored using measures of centrality, including degree centrality, betweenness centrality (brokerage), and eigenvector centrality, to examine different dimensions of character connectivity and structural importance.
